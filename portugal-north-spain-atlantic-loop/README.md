# Portugal + Northern Spain Atlantic Loop — September 2027

**Optimized route:** **Faro → Lagos → Lisbon/Sintra → Coimbra → Porto** *(public transport)* → **Viana do Castelo → Vigo/Cíes → Santiago → Costa da Morte → A Coruña → As Catedrais → Asturias/Picos → Santander → Bilbao → Burgos → León → Bragança/Douro → Porto** *(rental car)*.

## Why this is better than simply “drive north and drive the same way back”
- Avoids paying for/parking a car in the big Portuguese cities.
- Uses the car only where it unlocks beaches, mountain trailheads, fishing towns and coastal detours.
- After Bilbao, returns **inland** instead of retracing Galicia/Asturias, adding Burgos/León/Douro with little wasted geography.
- September is close to ideal for the Algarve **and** one of the better hiking periods in Asturias/Picos.

## Recommended duration
- **Full:** 30 days (28-day cut available).
- **60:40:** ~12 days.

## Top experiences
1. Ponta da Piedade, Lagos
2. Lisbon + Sintra
3. Porto + Douro
4. Cíes Islands
5. Santiago de Compostela
6. Costa da Morte
7. Praia das Catedrais at low tide
8. Covadonga/Picos + Ruta del Cares
9. Basque coast / Gaztelugatxe
10. Bilbao + Guggenheim

## Flight strategy
For September 2027, use an **open-jaw VIE/BUD → Faro, Porto → VIE/BUD** search. September 2027 is not yet searchable in the connected Skyscanner month tool (more than one year out). Current September 2026 proxy data showed VIE→FAO direct from €44 and OPO→VIE connecting from €42, so the route structure is promising, but these are **not 2027 prices**.

## Key booking traps
- Cíes capacity/ferry.
- As Catedrais **reservation in September + low tide**.
- Picos weather/access controls.
- Gaztelugatxe free reservation on controlled dates.
- Rental must explicitly allow Portugal↔Spain crossing.
