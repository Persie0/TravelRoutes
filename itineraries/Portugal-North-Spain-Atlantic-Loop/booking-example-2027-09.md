# Worked booking example — 1–30 September 2027

This is a planning calendar, **not a claim that September 2027 flights are on sale yet**.

- **1 Sep:** fly VIE/BUD → Faro; Faro night.
- **2 Sep:** Ria Formosa/Tavira.
- **3–4 Sep:** Lagos.
- **5–7 Sep:** Lisbon/Sintra.
- **8 Sep:** Coimbra.
- **9–11 Sep:** Porto + Douro.
- **12 Sep:** collect Porto rental car; start coast.
- **12–17 Sep:** Minho/Galicia through A Coruña.
- **18 Sep:** target As Catedrais, but choose exact time from the official tide table + reserve access.
- **19–23 Sep:** Asturias/Picos/Santander.
- **24–25 Sep:** Bilbao.
- **26–28 Sep:** inland scenic return via Burgos/León/Bragança/Douro; return car Porto.
- **29 Sep:** Porto buffer.
- **30 Sep:** fly OPO → home.

## Booking order
1. International flights once September 2027 inventory opens.
2. Porto rental car with explicit Portugal↔Spain permission.
3. Cíes ferry/park authorization.
4. As Catedrais authorization + tide alignment.
5. Picos accommodations (keep cancellable where possible).
6. Gaztelugatxe free reservation if controlled access applies on your date.
7. Long-distance Portugal rail/bus when timetables open.
