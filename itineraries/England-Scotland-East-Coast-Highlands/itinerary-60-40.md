# 60:40 highlights route — 13 days

Goal: preserve roughly **70–75% of the full route’s weighted experience value in ~43% of the time**.

| Day | Sleep | Core plan |
|---:|---|---|
| 1 | London | Arrive + Thames / Westminster orientation |
| 2 | London | Tower of London + City + St Paul’s |
| 3 | London | British Museum + Westminster; late train to York |
| 4 | Aberdeen | York Minster + medieval centre; late rail north to Aberdeen |
| 5 | Aviemore | Pick up car; Royal Deeside / Braemar → Cairngorms |
| 6 | Torridon | Short Cairngorms morning if clear → Inverness/Culloden → west to Torridon |
| 7 | Portree | Torridon scenery → Bealach na Bà / Applecross → Skye |
| 8 | Portree | Storr + Quiraing + Trotternish |
| 9 | Portree / Broadford | Elgol / Loch Coruisk or Cuillin day |
| 10 | Glencoe | Skye → Mallaig ferry → Glenfinnan → Glencoe |
| 11 | Edinburgh | Glencoe hike / scenic morning → Edinburgh; return car |
| 12 | Edinburgh | Castle + Old Town + Arthur’s Seat |
| 13 | — | Flexible Edinburgh half-day + flight home |

## Full vs 60:40

| Place | Full route | 60:40 | Reason |
|---|:--:|:--:|---|
| London | ✓ | ✓ | Non-substitutable, huge experience density |
| Oxford | ✓ | — | Excellent but expendable under time pressure |
| York | ✓ | ✓ | Best historic stop on the northbound rail line |
| Durham | ✓ | — | Great cathedral, but the extra stop costs momentum |
| Newcastle | ✓ | — | Good city; lower uniqueness than Highlands |
| St Andrews | ✓ | — | Strong but geographically secondary |
| Aberdeen / Dunnottar | ✓ | partial | Aberdeen kept as logistics pivot; Dunnottar cut in sprint |
| Cairngorms | ✓ | ✓ | High landscape value and natural transition into Highlands |
| Assynt | ✓ | — | Major sacrifice: superb, but northern detour costs 2–3 days |
| Torridon / Applecross | ✓ | ✓ | Highest-value west-coast driving/hiking geometry |
| Skye | 3 days | 2 days | Keep strongest island experiences |
| Glencoe | ✓ | ✓ | Essential landscape and natural route south |
| Stirling | ✓ | — | Cut to preserve outdoor time |
| Edinburgh | 3–4 days | 1.5–2 days | Still enough for core sights |

## Biggest sacrifice

**Assynt** is the painful deletion. It is spectacular, but a 60:40 route must avoid the northward loop from Inverness before turning south-west again. If scenery matters more than London, trade one London day plus York for 2 Assynt days.
