# 60:40 highlights route — ~12 days

Goal: keep roughly the best 60% of the trip's distinct scenery in about 40% of the time.

## Route

**Evenes/Svolvær → Lofoten → Reine → ferry to Bodø → fly to Bergen → Aurland/Flåm → Loen → Geiranger → Ålesund**

| Day | Sleep | High-value plan |
|---:|---|---|
| 1 | Svolvær | Fly into Evenes, pick up car, drive to Lofoten |
| 2 | Svolvær | Henningsvær + mountain/coast loop |
| 3 | Reine | Nusfjord, beaches, Hamnøy/Reine |
| 4 | Reine | Reinebringen or Ryten/Kvalvika; weather buffer |
| 5 | Bergen | Moskenes–Bodø ferry, strategic domestic flight to Bergen |
| 6 | Bergen | Bryggen + Fløyen/Ulriken |
| 7 | Aurland | Drive to Aurland/Flåm, Stegastein |
| 8 | Loen | Aurlandsfjellet/Sognefjord → Loen |
| 9 | Loen | Lovatnet / Via Ferrata or glacier-valley day |
| 10 | Geiranger | Gamle Strynefjellsvegen if open → Geiranger |
| 11 | Geiranger | Fjord viewpoints + hike |
| 12 | Ålesund | Drive to Ålesund; fly home late/next morning |

## What is cut

| Place | Full | 60:40 | Reason |
|---|---:|---:|---|
| Tromsø/Kvaløya | ✓ | – | good, but less unique than Lofoten for a first short trip |
| Senja | ✓ | – | excellent, but repeats dramatic north-coast mountain scenery |
| Andøya/Vesterålen | ✓ | – | transfer-efficient in full route, expendable in condensed route |
| Lofoten | ✓ | ✓ | highest northern value density |
| Bodø | ✓ | transfer | used only to connect ferry + flight |
| Trondheim | ✓ | – | culture stop; lower nature-value/hour |
| Atlantic Road | ✓ | – | iconic but short and geographically off compact axis |
| Geiranger/Loen | ✓ | ✓ | highest fjord/mountain value |
| Sognefjord/Aurland | ✓ | ✓ | distinct fjord + high-road experience |
| Bergen | ✓ | ✓ | best city anchor and flight hub |
| Hardanger | ✓ | – | strong, but overlaps fjord scenery |
| Preikestolen/Stavanger | ✓ | – | excellent but too far south for 12-day geometry |

**Estimated preserved normalized experience value:** roughly **62–68%**, depending on how heavily hiking and cities are weighted.
