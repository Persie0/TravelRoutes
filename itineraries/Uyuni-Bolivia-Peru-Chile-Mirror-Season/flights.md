# Flight strategy — cheaper start and cheaper finish

Research snapshot: **27 August 2026**. All prices below are indicative fare-market observations, not guaranteed quotes.

## Recommendation

For the full route, price this first:

> **VIE/BUD → Lima (LIM) // Santiago (SCL) → VIE/BUD**

This is the best route geometry because Lima starts the north-to-south Andes chain and Santiago is the natural exit after the one-way Uyuni→San Pedro crossing.

## Indicative long-haul anchors

| Shell | Current indicative observation | Interpretation |
|---|---:|---|
| VIE ↔ LIM | from roughly **€760 return** in recent Skyscanner results; February shown cheapest | strongest Austrian gateway anchor found |
| BUD ↔ LIM | roughly **€845 return** in current results | useful comparison, not automatically cheaper than VIE |
| BUD ↔ SCL | roughly **€817 return** in February examples | competitive Chile gateway |
| VIE ↔ SCL | roughly €766–€1,000+ depending provider/date snapshot | can be strong; inventory varies widely |
| VIE ↔ VVI (Santa Cruz) | roughly **€956+ return** | usually a weaker long-haul shell for this route |
| MAD ↔ VVI | nonstop Air Europa / BoA available | useful positioning fallback from VIE/BUD |

## Raw cheapest versus total value

A €760 Lima return can look cheaper than an €850–950 open-jaw ticket. But if the route ends in Chile, a Lima return adds:

- SCL→LIM positioning airfare;
- baggage fees on another ticket;
- airport transfers;
- potentially an overnight connection buffer;
- separate-ticket misconnection risk;
- roughly half to a full day of lost trip time.

Therefore compare **complete trip cost**, not headline fare.

## Open-jaw decision rule

Prefer the Lima-in / Santiago-out multi-city ticket if it is within roughly **€150–250** of the best practical same-airport return. The exact threshold depends on baggage and whether a separate-ticket overnight is required.

## Four shells to price before buying

1. **VIE → LIM // SCL → VIE** — default.
2. **BUD → LIM // SCL → BUD** — compare Hungary pricing.
3. **BUD → LIM // SCL → VIE** and the reverse — useful if separate one-ways price sensibly.
4. **VIE/BUD → MAD + MAD ↔ VVI nonstop** — Bolivia-heavy fallback only if open-jaw South America pricing is poor.

## Why not start in Santa Cruz?

Santa Cruz is low altitude and can be a pleasant acclimatization-free arrival, but it pulls the route east and creates a long positioning leg before the highland sights. Current fare anchors are also weaker than Lima. It only wins if a Madrid→VVI nonstop combination is unusually cheap on the exact dates.

## Why not finish in La Paz?

Finishing in La Paz means either:

- returning north from Uyuni/Sur Lípez; or
- skipping the elegant one-way crossing into Atacama.

Santiago is geographically farther from Europe but much better aligned with the route: San Pedro→Calama is short and Calama→Santiago is a frequent nonstop domestic link.

## Internal flights worth monitoring

- LIM→AQP.
- LPB→SRE for the full route (schedule-dependent).
- LPB→UYU for the 60:40 route.
- CJC→SCL.

## Booking caveats

- February is high-value for Uyuni mirror conditions, not necessarily the absolute lowest-fare period for every airline.
- When combining separate tickets through Madrid, Lima or Santiago, price an overnight buffer unless the connection is protected.
- Compare checked-baggage inclusion before selecting the lowest fare.
- Reprice the open jaw as both a multi-city ticket and two one-ways; international airline pricing can make either structure cheaper.
