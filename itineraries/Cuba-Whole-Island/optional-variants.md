# Only meaningful Cuba itinerary variants

No variant should be booked while countrywide non-essential travel restrictions/warnings and serious infrastructure disruption remain unresolved. Verify relevant BMEIA advice, and eastern-province access separately.

## 1. 18–21-day west-and-centre first trip — most robust when travel resumes

Havana (3) → Viñales (3) → Las Terrazas (1) → Playa Larga (2) → Cienfuegos (2) → Trinidad / Escambray (4–5) → Santa Clara/Remedios (1–2) → Havana (1–2). **Why:** avoids a 17+ hour intercity exit and the currently warning-affected east, while preserving almost all signature western/central experiences. This is the recommended practical longer option before the whole-island connection is proven.

## 2. Specialist diving / reef-heavy, 21–28 days

Replace Bayamo / Santiago / Baracoa with Playa Girón extended snorkeling, possible María la Gorda or Cayo Largo if an actual transfer works. **Jardines de la Reina** liveaboard requires its own costly, multi-day expedition; do not assume transport/service availability or a reef outing while medical/evacuation support is restricted. During unsafe conditions, postpone.

## 3. Beach-heavy relaxation, 14–21 days

Havana → Viñales → Playa Larga → Trinidad/Playa Ancón → Varadero or one northern cay → Havana. A worthwhile alternative if beach time is the priority, but compared with full cultural route it duplicates tropical coast settings and generally increases resort spend.

## 4. Eastern Cuba only, 9–13 days (future)

Santiago de Cuba → Sierra Maestra → Baracoa/Humboldt → Santiago (or verified eastern airport departure). Cultural and biodiversity value is very high, but not advisable as of the November 2026 warnings and fuel crisis. Consider only after services/recovery and official guidance improve.

## Flight variant

A true **Havana-in / Holguín- or Santiago-out** open-jaw would reduce major backtracking, but no reliable February 2027 VIE–HOG fare was returned and Santiago flight options are vulnerable to disruption. Do not list it as the default without an actual bookable through-ticket and a protected exit plan. See [flights.md](flights.md).
