# General ~28-day Cuba route: choice and sequence

**Length:** 28 calendar days, including international arrival/departure. **When:** ideally February or March, conditional on travel advisories. **Start/end:** Havana (HAV). **Mode:** casas particulares and confirmed bus/driver legs. **Main weakness:** very long eastern return; only justify it for a genuine whole-island trip.

### Geographic route

Havana (3 nights) → Viñales (3) → Las Terrazas/Soroa transit → Havana (1) → Playa Larga (2) → Cienfuegos (1) → Trinidad (4) → Santa Clara (1) → Remedios (1) → Camagüey (1) → Bayamo (1) → Sierra Maestra/Santo Domingo (1) → Santiago de Cuba (3, including transit arrival) → Baracoa (3) → Santiago return / Havana buffer → depart HAV.

This is a **planning geometry**, not guaranteed daily transport availability: the 2026 fuel crisis can invalidate it. For each exact daytime/overnight stop see the authoritative [28-day day-by-day table](itinerary-28-days.md).

### Stop priorities and how much time is justified

| Base | Comfortable sightseeing time | Core reason |
|---|---:|---|
| Havana | 2.5–3 days, plus transit night | Historic heart, fortifications, live arts |
| Viñales | 2–3 days | Mogotes, hiking, caves, rural landscape |
| Zapata / Bay of Pigs | 1.5–2 days | Reef, sinkhole, wetlands |
| Cienfuegos | 0.5–1 day | UNESCO French-influenced city; El Nicho nearby |
| Trinidad | 3–4 days | Historic core, valley, Escambray, beaches |
| Santa Clara/Remedios | 1–2 days | Historical sites and less-touristed square |
| Camagüey | 0.5–1 day | UNESCO historic centre |
| Bayamo/Sierra Maestra | 1.5–2 days | Mountain and revolutionary history |
| Santiago | 2 days | Different cultural character, forts, coffee heritage |
| Baracoa | 2–3 days | El Yunque, Humboldt rain forest; wet-season contingency |

### Main route alternatives

- **13-ish days:** west/central [60:40](itinerary-60-40.md) (12 days in the current optimized schedule).
- **23 days:** [Speedrun](itinerary-speedrun.md), all fixed-route S/A entries, fewer leisure/rest days but no cancellation-risk magic.
- **21 days:** efficient west/central extended version for a first trip in unstable conditions; cut Camagüey and everything east of Remedios, spend saved days on safe local nature and beaches.
