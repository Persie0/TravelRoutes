# General ~28-day optimized route

## Route

**Cape Town → Windhoek → Sossusvlei → Walvis Bay/Sandwich Harbour → Swakopmund → Spitzkoppe → Twyfelfontein → Etosha → Rundu → Divundu/Mahango → Mohembo border → Maun/Okavango → Moremi → Khwai → Savuti → Kasane/Chobe → Victoria Falls.**

This is the best ~28-day first-trip cut because it preserves the trip's highest-value ecosystems while removing long detours that can be substituted on another trip.

## Day allocation

| Days | Place | Why it survives the cut |
|---|---|---|
| 1–4 | Cape Town + Peninsula | S-tier city/nature density; four days can include peninsula and a short Winelands block |
| 5 | CPT→WDH | strategic flight avoids ~14h road positioning |
| 6–7 | Sossusvlei | globally distinctive dunes/Deadvlei; cannot compress to a drive-by |
| 8–9 | Walvis / Sandwich Harbour / Swakop | dunes-meet-ocean experience is more unique than another city day |
| 10 | Spitzkoppe | efficient scenic overnight between coast and Damaraland |
| 11 | Twyfelfontein / Damaraland | UNESCO rock art; good route fit |
| 12–14 | Etosha | three safari days protect dawn/dusk and waterhole time |
| 15 | Rundu | necessary transit reset |
| 16–17 | Divundu / Mahango | breaks the Etosha→Botswana transfer and adds a lush river ecosystem |
| 18 | Divundu→Maun via Mohembo | direct west-Botswana entry; Tsodilo becomes optional on this compressed route |
| 19 | Okavango from Maun | mokoro/boat + optional scenic flight |
| 20–24 | Moremi→Khwai→Savuti→Kasane | core remote Botswana traverse |
| 25 | Chobe | land + boat perspectives |
| 26 | Kasane→Victoria Falls | return car; short international transfer |
| 27 | Victoria Falls | full waterfall day + optional Zambia side |
| 28 | Victoria Falls | flight home / safety buffer |

## What is cut versus 42 days

| Cut | Reason |
|---|---|
| Garden Route | excellent, but 3–4 days + positioning; Cape Peninsula already provides a strong coast block |
| Hermanus | seasonal and easy future add-on from Cape Town |
| extra Swakop rest day | low marginal sightseeing value |
| dedicated desert-wildlife tracking day | strong, but Etosha/Botswana already provide large wildlife blocks |
| Tsodilo full day | worthwhile but takes time from delta/safari; keep only if border timing works |
| Nxai/Makgadikgadi | distinctive but lower value per transfer day than Moremi/Khwai/Savuti |
| extra Khwai/Savuti nights | preserve the traverse, trim repetitions |
| extra Vic Falls buffer | retain one full day + departure buffer only |

## Minimum vehicle standard

The **Moremi–Khwai–Savuti** part is not an ordinary road trip. A real 4×4, remote-travel preparation and booked camps are required. If that experience level is missing, keep the geography but use a guided mobile safari from Maun and reconnect in Kasane.
