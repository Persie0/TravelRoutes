# 60:40 Highlights Route — ~14 Days

Goal: preserve roughly 60%+ of the trip's unique experience value in about half the time. The condensed route spends disproportionately more time in Finnish Lapland because that is the least replaceable part of the full route.

| Day | Sleep | Core experience |
|---:|---|---|
| 1 | Helsinki / night train | Helsinki highlights + sleeper north |
| 2 | Oulanka | Rovaniemi pickup → Oulanka |
| 3 | Oulanka | Pieni Karhunkierros |
| 4 | Pyhä-Luosto | Riisitunturi at early/late light → Pyhä |
| 5 | Saariselkä | Pyhä-Luosto hike → drive north |
| 6 | Saariselkä | Urho Kekkonen NP |
| 7 | Inari | Sámi culture + Lake Inari / Pielpajärvi |
| 8 | night train | Return Rovaniemi → sleeper south |
| 9 | Tallinn | Helsinki ferry → Tallinn Old Town |
| 10 | Lahemaa | Viru Bog + north coast; RMK hammock night |
| 11 | Riga | Return Tallinn → fast bus to Riga |
| 12 | Gauja NP | Sigulda/Turaida/Gauja hike |
| 13 | Vilnius | Riga → Vilnius; Old Town evening |
| 14 | Vilnius / home | Vilnius + Trakai if flight allows |

## Full vs 60:40
| Place | Full route | 60:40 | Reason |
|---|---|---|---|
| Oulanka | yes | **yes** | Best single Finnish hiking value |
| Riisitunturi | yes | **yes** | Distinctive blanket-bog fell landscape, low detour |
| Pyhä-Luosto | yes | **yes** | Strong geology + route continuity |
| Saariselkä/UKK | yes | **yes** | True fell/wilderness feel |
| Inari | yes | **yes** | Adds Sámi culture, not just more forest |
| Pärnu | yes | no | Pleasant, but replaceable |
| Kuldīga | yes | no | Beautiful but westward detour |
| Curonian Spit | yes | no | Painful cut; excellent place but time-expensive geometry |
| Kaunas | yes | no | Lower uniqueness per transfer hour |
| Warsaw | yes | no | Strong city, but Poland is the easiest major cut |
| Kraków | yes | no | Excellent, but detached from nature core in a 14-day trip |

Estimated normalized experience retained: **~63–68%** of the full-route score, depending how heavily you value Polish culture vs Nordic nature.
