# Guatemala → Belize → Mexico — optimized ~28-day route

This folder contains a **general 3–4 week route** plus a **February 2027 worked example** using current Rome2Rio routing and indicative Skyscanner fare research.

Research snapshot: **2026-08-23**.

> Prices, schedules, border procedures, opening hours, volcanic activity and weather can change. Treat fare figures as snapshots and transport durations as planning estimates; re-check before booking.

## General master route

**Europe → Guatemala City → Antigua → Acatenango/Fuego → Lake Atitlán → Semuc Champey → Flores → Tikal (+ Yaxhá) → San Ignacio → Belize City transit → Caye Caulker → Bacalar → Valladolid → Chichén Itzá (+ Ek Balam) → Cancún → Europe**

For the complete day-by-day version, use **[`general-28-day-route.md`](./general-28-day-route.md)**.

### Why this order is better than the original draft

1. **No Lake Atitlán → Guatemala City backtrack.** Continue directly toward Lanquín/Semuc Champey.
2. **Belize City becomes transit rather than a mandatory overnight.** San Ignacio → Belize City → Caye Caulker is normally a same-day connection.
3. **Bacalar breaks the worst overland leg.** Rome2Rio shows Caye Caulker→Valladolid around 10 hours by ferry/bus; stopping at Bacalar turns that into two useful legs while adding a strong destination.
4. **Valladolid, not Cancún, is the Chichén Itzá base.** Mexico's tourism ministry puts Chichén Itzá around 45 km from Valladolid; Ek Balam is also nearby.
5. **Cancún stays short.** It works extremely well as the final beach/flight hub but is not the strongest surf reason to add days.
6. **Mexico City is optional.** It is worth 2–4 days if trip length or fares allow, but should not force the core route into a sprint.
7. **If surfing matters, El Paredón is the more logical surf add-on.** It is a detour from Antigua, so add it only if surfing is a real priority.

## Recommended 28-day allocation

| Days | Base / move | Main focus |
|---|---|---|
| 1–5 | Antigua + Acatenango | UNESCO Antigua, Acatenango/Fuego 2D/1N, recovery/weather buffer |
| 6–8 | Lake Atitlán | San Juan + Santiago/Santa Catarina + slower lake day |
| 9–11 | Semuc Champey | long transfer, mirador + pools, transfer to Flores |
| 12–14 | Petén | Tikal, optional Yaxhá sunset, Flores→Belize |
| 15–17 | San Ignacio | ATM Cave, Xunantunich/Cahal Pech, optional Caracol/Mountain Pine Ridge |
| 18–21 | Caye Caulker | Hol Chan/Shark Ray Alley, Blue Hole/Lighthouse Reef, weather buffer |
| 22–23 | Bacalar | border transfer + Lagoon of Seven Colors |
| 24–27 | Valladolid/Yucatán | Valladolid, Chichén Itzá + cenote, Ek Balam, transfer to Cancún |
| 28 | Cancún → Europe | fly home |

## Best season

For the **whole route**, the strongest broad window is roughly **December through April**, with **February–March** the most balanced combination of Guatemala highland visibility, Belize dry-season conditions and Yucatán comfort.

Belize's National Meteorological Service defines most of **June–November as the rainy season**, while NOAA's official Atlantic hurricane season runs **June 1–November 30** and climatological activity peaks around September. Those factors make late summer/early autumn the weakest time for this particular reef + volcano + overland itinerary.

## February 2027 worked example

The route also has a concrete **Feb 1–28, 2027** example in **[`itinerary.md`](./itinerary.md)**.

Current indicative Skyscanner observations used there include:

- **BUD → GUA Feb 1: ~€453**
- **VIE → GUA Feb 1: ~€472**
- **CUN → BUD Feb 28: ~€358**
- **CUN → VIE Feb 26: ~€400**

That makes:

- **BUD→GUA + CUN→BUD ≈ €811** raw long-haul fare, but requires Budapest positioning at both ends if starting in Vienna.
- **VIE→GUA + CUN→BUD ≈ €830** and removes the outbound Vienna→Budapest positioning leg, so it can easily be the better door-to-door choice despite the ~€19 higher airfare.
