# Canonical ~28-day itinerary

The detailed date-agnostic day-by-day itinerary is maintained in:

**[`general-28-day-route.md`](./general-28-day-route.md)**

That file is the canonical full route. The summary allocation is:

| Days | Base / move | Focus |
|---|---|---|
| 1–5 | Antigua + Acatenango | UNESCO Antigua, 2D/1N volcano trek, recovery/weather buffer |
| 6–8 | Lake Atitlán | San Juan + another village + slower lake day |
| 9–11 | Semuc Champey | transfer, mirador/pools, transfer to Flores |
| 12–14 | Petén | Tikal, Yaxhá/Flores, Belize border |
| 15–17 | San Ignacio | ATM, Xunantunich/Cahal Pech, optional Cayo extra |
| 18–21 | Caye Caulker | Hol Chan, Blue Hole/reef, weather buffer |
| 22–23 | Bacalar | border transfer + lagoon |
| 24–27 | Valladolid / Yucatán | Valladolid, Chichén, Ek Balam, Cancún transfer |
| 28 | Cancún | fly home |

The route deliberately uses **Bacalar as a useful transit break** and treats **Belize City as transit** rather than a compulsory overnight.
